## What was done
- Implemented the `glab gpg-key` subcommand.
- Added four new commands for GPG key management:
    - `glab gpg-key add [key-file]`: Adds a GPG key to a GitLab account.
    - `glab gpg-key list [--show-id]`: Lists all GPG keys for the authenticated user.
    - `glab gpg-key get <key-id>`: Retrieves a specific GPG key by its ID.
    - `glab gpg-key delete <key-id>`: Deletes a specific GPG key by its ID.

## Impact
- Users can now perform full lifecycle management of GPG keys on their GitLab account directly from the command line, streamlining workflows for commit signing and verification.
- This is a new feature and introduces no breaking changes.

## Technical details
- Extends the `glab` command-line interface with a new top-level subcommand, `gpg-key`.
- Integrates with GitLab's API to perform CRUD operations on user GPG keys.
