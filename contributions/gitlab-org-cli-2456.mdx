## What was done
- Added `glab gpg-key add [key-file]` to upload a GPG key.
- Added `glab gpg-key list [--show-id]` to display GPG keys for the authenticated user.
- Added `glab gpg-key get <key-id>` to retrieve a specific GPG key by ID.
- Added `glab gpg-key delete <key-id>` to remove a specific GPG key by ID.

## Impact
- Users can now conveniently manage their GPG keys directly via the `glab` command-line interface.
- Improves efficiency for tasks requiring GPG key interaction, such as signing commits.
- No breaking changes introduced.

## Technical details
- New subcommands were implemented under `glab gpg-key` to interact with GitLab's API endpoints for GPG key management.
- The implementation adds support for basic CRUD (Create, Read, Update, Delete) operations on GPG keys through the CLI.
