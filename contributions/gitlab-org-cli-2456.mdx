## What was done
- Implemented `glab gpg-key add [key-file]` to upload a GPG key to a GitLab account.
- Added `glab gpg-key list [--show-id]` to display all GPG keys for the authenticated user.
- Introduced `glab gpg-key get <key-id>` to retrieve details of a specific GPG key by its ID.
- Included `glab gpg-key delete <key-id>` to remove a GPG key from a GitLab account.

## Impact
- Users can now perform comprehensive GPG key management operations (add, list, get, delete) directly through the `glab` CLI.
- Streamlines the process of managing GPG keys for signing commits and tags without needing to access the GitLab UI.

## Technical details
- New `gpg-key` command group added to the `glab` CLI, including subcommands for various management operations.
- These commands interact with the GitLab API to facilitate GPG key interactions.
- Includes updated documentation for the new CLI functionalities.
