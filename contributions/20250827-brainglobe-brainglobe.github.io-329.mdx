## What was done
- Configured Sphinx as the documentation generator for the project.
- Integrated the Sphinx autodoc extension to extract API documentation directly from Python docstrings.
- Added new documentation pages to display the generated API reference.
- Established a workflow for automatically building and updating API documentation.

## Impact
- Improved the completeness and accuracy of the API documentation available to users and contributors.
- Streamlined the documentation maintenance process by automating API reference generation.
- Enhanced developer experience by providing up-to-date and easily accessible API details.

## Technical details
- Utilized Sphinx for the overall documentation framework.
- Employed `sphinx.ext.autodoc` to parse Python docstrings and generate corresponding API reference pages.
- Modified Sphinx configuration files (e.g., `conf.py`) to enable autodoc and specify source directories.
- Incorporated generated API documentation into the website's navigation structure.
