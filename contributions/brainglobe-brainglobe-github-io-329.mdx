## What was done
- Added `fetch_external.py` script to clone or pull specified external Brainglobe repositories (e.g., `brainglobe-atlasapi`) into an `external/` directory, making their code available for documentation.
- Updated Sphinx configuration (`docs/source/conf.py`) to include the paths of external repositories in `sys.path` and enabled necessary extensions like `sphinx.ext.autodoc`, `sphinx.ext.autosummary`, and `sphinx.ext.coverage`.
- Created reStructuredText (`.rst`) API reference files (e.g., `docs/source/api/brainglobe_atlasapi.rst`) that use Sphinx's `automodule` directive to automatically generate documentation from Python docstrings.
- Integrated the new API documentation into the main site structure by linking it from relevant index files (e.g., `docs/source/documentation/brainglobe-atlasapi/index.md`).
- Modified the GitHub Actions workflow (`.github/workflows/docs_build_and_deploy.yml`) to set up Python, execute `fetch_external.py` (to fetch external dependencies), and build the Sphinx documentation.
- Cleaned up temporary test documentation files and refined `sys.path` configurations.

## Impact
- **For Users**: Provides automatically generated, comprehensive, and up-to-date API documentation for core Brainglobe libraries directly on the Brainglobe website.
- **For Developers**: Automates the process of generating API documentation, significantly reducing manual effort and ensuring consistency across various Brainglobe projects. The CI/CD integration ensures the documentation remains current with code changes.

## Technical details
- Utilizes **Sphinx** as the primary documentation generator.
- Employs **`sphinx.ext.autodoc`** and **`sphinx.ext.autosummary`** for automatic extraction of documentation from Python docstrings.
- Introduces a custom Python script (`fetch_external.py`) for managing Git repositories of external dependencies during the documentation build process.
- Integrates these steps within **GitHub Actions** to automate documentation builds and deployment on every push.
