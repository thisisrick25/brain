## What was done
- Added `glab repo members add` command to assign users to a project by username or user ID.
- Implemented `glab repo members remove` command to unassign users from a project by username or user ID.
- Enabled setting various GitLab access levels (Guest, Reporter, Developer, Maintainer, Owner) and optional expiration dates when adding members.

## Impact
- Users can now manage project members directly from the GitLab CLI, simplifying team management workflows.
- No breaking changes were introduced.

## Technical details
- New commands are integrated under `glab repo members` to extend repository management capabilities.
- API interactions for member management are handled with robust HTTP mocking, ensuring reliability and testability.
- The implementation supports flexible user input, accepting both usernames and user IDs for member identification.
