## What was done
- The `glab stack sync` command was updated to accept and process command-line options specifically for `git push`.
- The command's interface was extended to allow users to specify standard `git push` flags.

## Impact
- Users can now utilize various `git push` options directly with `glab stack sync`, providing greater control over the push operation.
- This enhancement improves the flexibility and power of the `stack sync` command for advanced Git workflows.

## Technical details
- The `stack sync` command's argument parsing was modified to identify and capture options intended for the underlying `git push` operation.
- These captured `git push` options are then correctly forwarded to the Git client when `glab stack sync` executes the push.
