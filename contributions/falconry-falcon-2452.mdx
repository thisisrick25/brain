## What was done
- Updated the `project.license` declaration in `pyproject.toml` from a table to a direct string following SPDX expression format.
- Changed the license identifier from `"Apache 2.0"` to the SPDX-compliant `"Apache-2.0"`.
- Added `license-files = ["LICENSE"]` directly under the `[project]` section.
- Removed the redundant `license-files` entry from `[tool.setuptools]`.
- Increased the minimum required `setuptools` version from `>=61` to `>=77.0.3`.
- Removed the redundant `License :: OSI Approved :: Apache Software License` classifier from `pyproject.toml`.

## Impact
- No direct impact on Falcon's runtime behavior or API for users.
- Developers and packagers will benefit from a more standard and consistent license declaration in `pyproject.toml`.
- The build process now requires a newer version of `setuptools`.

## Technical details
- Adheres to best practices for license declaration in `pyproject.toml` using SPDX license expressions, as recommended by modern Python packaging standards (e.g., PEP 639).
- Streamlines `pyproject.toml` by removing redundant entries and ensuring correct license metadata.
