## What was done
- Updated `pyproject.toml` to define `project.license` directly as a string, using the SPDX-compliant "Apache-2.0" identifier.
- Added `license-files = ["LICENSE"]` at the top-level `[project]` table in `pyproject.toml`.
- Upgraded the `setuptools` build-system requirement in `pyproject.toml` from `>=61` to `>=77.0.3`.
- Removed a redundant `license-files` entry from the `[tool.setuptools]` section.
- Eliminated the redundant `License :: OSI Approved :: Apache Software License` classifier.

## Impact
- Improves adherence to modern Python packaging standards (PEP 639), specifically regarding license declaration.
- Ensures compatibility with recent and future `setuptools` versions for building the package.
- No functional changes or breaking impacts for users of the Falcon framework.

## Technical details
- Changes primarily modify the project's build metadata within `pyproject.toml`.
- Adopts SPDX license identifiers for machine-readable license information, replacing a less formal text description.
- Updates build-time dependency version constraints for `setuptools`.
