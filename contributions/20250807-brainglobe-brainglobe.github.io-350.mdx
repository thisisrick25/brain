# Contribution Summary

## What was done

- The import alias for the `brainglobe_space` library was updated from `bg` to `bgs` in all Python code examples throughout the documentation.
- The alias used for `brainglobe_space` was standardized across the documentation to ensure uniformity.

## Impact

- Improves consistency across all code examples, making it easier for users to follow and understand the documentation without encountering varied aliases for the same library.
- Enhances readability and reduces potential confusion for new users learning `brainglobe_space`.
- Aligns the documentation with a single, consistent alias, fostering a more cohesive user experience.

## Technical details

- The changes primarily involved text replacements within Python code blocks embedded in the documentation files.
- Specifically, `import brainglobe_space as bg` was changed to `import brainglobe_space as bgs` wherever it appeared in example code.
- This modification impacts various Python code examples found across the `brainglobe.github.io` repository, ensuring that all demonstrate the library using the new, standardized `bgs` alias.
