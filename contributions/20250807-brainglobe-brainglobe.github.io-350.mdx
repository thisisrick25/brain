## What was done
- Updated the `brainglobe-space` documentation file (`docs/source/documentation/brainglobe-space/index.md`).
- Changed all Python code examples to use `import brainglobe_space as bgs` instead of `import brainglobe_space as bg`.

## Impact
- Users will now encounter a consistent and standardized import alias (`bgs`) for the `brainglobe_space` library throughout the documentation, improving clarity and readability of code examples.
- This change is purely a documentation update and introduces no breaking changes to the library or its functionality.

## Technical details
- The modification involved a global find-and-replace of the import alias within Python code blocks in a Markdown-based documentation file.
- The change applies specifically to the `brainglobe_space` library's representation in examples.
