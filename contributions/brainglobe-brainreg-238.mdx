## What was done
- Modified `brainreg/napari/register.py` to update parameter labels and add tooltips.
- Updated the labels for `z_pixel_um`, `y_pixel_um`, and `x_pixel_um` in the napari plugin's registration interface to explicitly include `(um)` (micrometers).
- Added comprehensive tooltips for the `z_pixel_um`, `y_pixel_um`, and `x_pixel_um` parameters, explaining their purpose and units.

## Impact
- **User-facing**: Users of the napari plugin will now see clearer labels for voxel size inputs, explicitly indicating units as micrometers. Hovering over these fields will provide helpful tooltips with additional context.
- No breaking changes.

## Technical details
- The changes involve modifying dictionary definitions for `napari_experimental_provide_function` parameters, specifically updating the `label` and adding a new `tooltip` key-value pair for the voxel size inputs.
