## What was done
- Modified `brainreg/napari/register.py` to update the napari plugin's interface.
- Appended `(um)` to the labels for `x_pixel_um`, `y_pixel_um`, and `z_pixel_um` voxel size parameters.
- Added comprehensive tooltips for the `x_pixel_um`, `y_pixel_um`, and `z_pixel_um` input fields, clarifying their purpose and units.

## Impact
- Users of the `brainreg` napari plugin will now see clearer, unit-specified labels (e.g., "Voxel size (z, um)") for voxel dimension inputs.
- Hovering over these input fields will display informative tooltips, aiding users in understanding the required values and units.
- This improves the overall usability and user experience by reducing ambiguity regarding input parameters.

## Technical details
- Changes were implemented within the `brainreg_register` function, specifically by modifying the `label` and adding `tooltip` dictionary entries for relevant parameters.
