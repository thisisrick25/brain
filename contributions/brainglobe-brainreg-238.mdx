## What was done
- Updated the labels for `z_pixel_um`, `y_pixel_um`, and `x_pixel_um` parameters in `brainreg/napari/register.py` to explicitly include " (um)", clarifying their units.
- Added informative tooltips to the `z_pixel_um`, `y_pixel_um`, and `x_pixel_um` input fields in the napari plugin, detailing the purpose and units of each voxel dimension.

## Impact
- Users of the brainreg napari plugin will now see clear unit specifications for voxel size inputs (e.g., "Voxel size (z, um)") and helpful tooltips, improving parameter understanding and usability.
- No breaking changes were introduced.

## Technical details
- Modified the dictionary definitions for napari parameter widgets within the `brainreg_register` function in `brainreg/napari/register.py`, specifically updating the `label` and adding `tooltip` keys.
