## What was done
- Updated the labels for `z_pixel_um`, `y_pixel_um`, and `x_pixel_um` parameters in `brainreg/napari/register.py` to include the unit `(um)`.
- Added tooltips to these voxel size parameters, providing detailed explanations (e.g., "Voxel size in the z-dimension (micrometers)").

## Impact
- Users of the `brainreg` napari plugin will now see clearer, more informative labels and tooltips for voxel size input fields, reducing ambiguity and improving the user experience.
- No breaking changes were introduced.

## Technical details
- The changes were implemented by modifying the `label` and adding `tooltip` dictionary entries for `napari` magic-GUI parameters in the `brainreg_register` function within `brainreg/napari/register.py`.
