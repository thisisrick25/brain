# Contribution Summary

## What was done

This contribution enhances the `brainreg` napari plugin by making the voxel size parameters more user-friendly and explicit. Specifically, the following improvements were implemented:

-   **Added Units to Voxel Size Labels**: The display names for voxel size input fields in the napari plugin's user interface now explicitly include their units (ee.g., "Voxel size (μm)"). This prevents ambiguity regarding the expected input scale.
-   **Provided Tooltips for Voxel Size Parameters**: Informative tooltips were added to the voxel size input fields. These tooltips offer additional context and guidance to users, explaining what the voxel size represents and potentially how it influences the registration process.

These changes directly address and close issue #223, which called for better clarity regarding voxel size units. The modifications were primarily focused on the user interface definition of the `brainreg` standardisation function exposed through the napari plugin.

## Impact

These changes significantly improve the user experience for anyone utilizing the `brainreg` napari plugin, particularly when performing brain registration and setting up data parameters.

-   **Enhanced Clarity**: Users will immediately understand the expected units for voxel size inputs, reducing the likelihood of incorrect data entry or misinterpretation. This is crucial for accurate brain registration.
-   **Improved Usability**: The addition of tooltips provides on-demand help and context, making the plugin more intuitive and reducing the need to consult external documentation for basic parameter understanding.
-   **Reduced Error Potential**: By explicitly stating units and providing explanations, the chances of users entering voxel sizes in incorrect units (e.g., mm instead of µm) are significantly lowered, leading to more robust and reliable registration results.
-   **Scope**: This impacts all users of the `brainreg` napari plugin who interact with the brain registration function's input parameters. There are no breaking changes; it is purely an additive quality-of-life improvement.
