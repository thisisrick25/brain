# Contribution Summary

## What was done

- Implemented the display of units alongside voxel size labels within the napari plugin's user interface.
- Added informative tooltips to the voxel size input fields in the brain registration function, clarifying the expected units and purpose.

## Impact

- Significantly improves the user experience by making voxel size parameters more intuitive and easier to understand for all users.
- Reduces ambiguity and potential for misinterpretation of voxel dimensions, leading to more accurate and reliable brain registration outcomes.
- Enhances the overall usability and accessibility of the `brainreg` napari plugin, especially for new users.

## Technical details

- Involved modifications to the napari plugin's UI components, specifically where voxel size inputs and their corresponding labels are rendered.
- Updates were made to Python code responsible for defining and managing the plugin's widgets and their property displays.
- The core technologies involved are Python and the Napari framework for building the plugin interface.
