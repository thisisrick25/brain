# Contribution Summary

## What was done

-   Units were explicitly added to voxel size labels within the napari plugin's user interface.
-   Tooltips were implemented for voxel size parameters in the brain registration function, offering helpful contextual information to users.

## Impact

-   Significantly improves user understanding and clarity regarding the expected units for voxel size inputs, preventing potential misinterpretations.
-   Enhances the overall user experience by making the plugin's interface more informative and intuitive.
-   Reduces the likelihood of user errors by providing clear guidance on parameter specifications directly within the UI.

## Technical details

-   The changes primarily involve modifications to the user interface generation logic of the `brainreg` napari plugin.
-   This includes updating string formatting for labels to append unit specifiers (e.g., "µm").
-   Tooltip functionality was added to relevant input fields or widgets associated with voxel size parameters.
-   This PR directly addresses and closes issue #223, fulfilling a request for clearer unit specification.
