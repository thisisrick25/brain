## What was done
- Updated the `docs/source/documentation/brainglobe-space/index.md` file.
- Changed the import alias for `brainglobe_space` from `bg` to `bgs` in all Python code examples.
- Modified subsequent function calls to use the new `bgs` alias (e.g., `bg.map_stack_to` became `bgs.map_stack_to`).

## Impact
- Users referencing the `brainglobe-space` documentation will now encounter consistent import aliases, improving clarity and reducing potential confusion.
- This change solely affects documentation examples and introduces no breaking changes to the `brainglobe_space` library itself.

## Technical details
- The modification involved a simple text replacement within code blocks in a Markdown file.
- The standardized alias `bgs` is now consistently used for `brainglobe_space`, aligning with common Python alias conventions.
