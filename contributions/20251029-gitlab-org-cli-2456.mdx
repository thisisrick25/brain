## What was done
- Implemented new `gpg-key` management functionality for the `glab` CLI.
- Added the following new commands:
    - `glab gpg-key add [key-file]` - Uploads a GPG key to your GitLab account.
    - `glab gpg-key list [--show-id]` - Displays all GPG keys for the authenticated user.
    - `glab gpg-key get <key-id>` - Retrieves details for a specific GPG key by ID.
    - `glab gpg-key delete <key-id>` - Removes a specific GPG key by ID.

## Impact
- Users can now manage their GitLab GPG keys directly through the `glab` command-line interface, including adding new keys, listing existing ones, fetching details, and deleting keys.
- Improves CLI usability for managing cryptographic identities associated with a GitLab account.
- No breaking changes were introduced.

## Technical details
- Introduces a new top-level command group, `glab gpg-key`, and its subcommands.
- Extends the `glab` CLI to interact with GitLab's API endpoints for GPG key management.
