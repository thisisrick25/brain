## What was done
- Implemented new subcommands for GPG key management under `glab`.
- Added functionality to create, list, and potentially delete GPG keys.
- Integrated with the GitLab API to interact with user GPG keys.

## Impact
- Users can now manage their GPG keys more efficiently without leaving the CLI.
- Streamlines the workflow for developers who sign commits or tags with GPG.

## Technical details
- Introduction of a new `gpg-key` command group within the CLI.
- Utilized existing GitLab API client to interact with relevant GPG key API endpoints.
- New command-line parsers and handlers were developed for GPG key operations.
